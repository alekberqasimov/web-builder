# Web Builder

A browser-based visual website builder inspired by block editors. It runs entirely on static HTML, CSS and JavaScript — no database, account or backend is required.

## Features

- Drag-and-drop section library
- Inline text editing
- Section colors, spacing, width and alignment controls
- Desktop, tablet and mobile previews
- Undo and redo
- Automatic browser storage
- Project JSON import/export
- Standalone website ZIP export

## Run locally

Open `index.html`, or serve the folder with any static server.

## Publish

The repository is ready for GitHub Pages. Use **Settings → Pages → Deploy from a branch**, select `main` and `/ (root)`.

Projects are stored in the current browser through `localStorage`. Export the project JSON periodically if you want a portable backup.
