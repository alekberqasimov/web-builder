# Web Builder — аудит качества и премиальной библиотеки

Дата: 6 сентября 2026. Исходная версия: `eeeac2ab38e8b810f03b94f5f140d77c68fffae6`.
Рабочая ветка: `premium-quality-audit`.

## Вывод

Проект имеет работоспособный функциональный фундамент: дерево элементов, адаптивные стили, drag-and-drop, локальные проекты, многоязычные страницы, SEO и статический экспорт. Главный продуктовый недостаток — смешение старых заготовок, PRO-композиций и инструментов без последовательного отбора. Технические риски сосредоточены на границах доверия (импорт/HTML), сохранении и расхождении предпросмотра с экспортом.

Выбрано развитие текущего движка с совместимостью сохранённых проектов. Полная перепись увеличила бы риск потери работающих редакторов и миграций; исключительно косметическая смена темы не устранила бы функциональные дефекты.

| 12 | P1 | Запись считалась успешной до завершения транзакции. | Ожидание transaction.complete, последовательная очередь записей и защита от устаревшего статуса. |
| 13 | P2 | Соединения IndexedDB не закрывались после операций. | Соединения закрываются после чтения/записи. |
| 14 | P1 | Произвольный HTML вставлялся непосредственно в DOM редактора. | HTML в canvas отображается в изолированном iframe без выполнения скриптов. |

## Каталог после отбора

12 основных PRO-композиций: Product Hero, Studio Hero, Bento, Video Story, Portfolio Mosaic, Logo Cloud, Metrics, Customer Story, Pricing, FAQ Split, Contact Conversion, CTA.

Сохранены пять нужных структурных блоков: меню, редактируемые карточки «фото + текст», галерея, текст, подвал. Девять функциональных блоков остаются доступными: формы, видео, встраивание, соцсети, карта, отзывы, вкладки, аккордеон, плавающая связь. Пустые контейнеры и свои секции находятся в собственных категориях.

Старые hero, features, cards, split, quote, cta, contact, faq, stats, testimonials, pricing, logos исключены из каталога. Удалять их код целиком нельзя: сохранённые проекты и миграции используют эти фабрики.

## Проверки и ограничения

Исходные 90 модульных тестов проходили. После изменений — 98 модульных тестов. GitHub Actions проверяет собранный production-артефакт, а не только исходники.

Браузерный прогон из 13 сценариев завершился успешно. Визуальная проверка затем обнаружила дефекты начального режима телефона и приоритета CSS в экспорте. Для финальной версии прогон расширен до всех 16 имеющихся браузерных сценариев.

Первый браузерный прогон обнаружил несовместимость тестовой настройки темы с sandbox: addInitScript писал localStorage во все фреймы. Настройка ограничена главным окном; изоляция предпросмотра сохранена. Ошибка не скрыта фильтром логов.

Проверка использует Chromium и эмуляцию размеров/касания. Она не заменяет тест на физических iPhone Safari и Android. Для пользовательских форм нужен реальный endpoint; доставка писем без него не проверяется. Пользовательский HTML и сторонние embed остаются доверенным авторским кодом в опубликованном сайте — sandbox защищает редактор, но не превращает произвольный сторонний код в безопасный.

Экспорт состоит из статических файлов. Защита сервера при распаковке зависит также от обновлений сервера, прав каталогов, механизма распаковки и запрета исполнения серверных скриптов. Эти параметры не доступны из GitHub Pages и не проверялись. Формулировка «все возможные ошибки устранены» не подтверждалась.
